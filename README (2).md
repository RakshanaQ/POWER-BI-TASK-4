# Power BI Task 4 - Dashboard

## 📊 Project Overview
This project is a Power BI dashboard created to analyze and visualize data using interactive charts, KPI cards, filters, and data-driven insights. The dashboard transforms raw data into meaningful visual information that helps users understand trends, comparisons, and overall performance.

## 🎯 Objectives
- Import and prepare data for analysis.
- Clean and transform the dataset using Power Query.
- Create meaningful KPIs and calculated measures using DAX.
- Analyze trends and comparisons using interactive visualizations.
- Provide filters and slicers for dynamic analysis.
- Present important insights through an easy-to-understand dashboard.

## 🛠️ Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Dashboard Features
- KPI Cards for important summary values
- Bar and Column Charts for comparisons
- Line Charts for trend analysis
- Tables/Matrix for detailed information
- Interactive Slicers
- Date-based filtering
- Dynamic visual interactions
- Summary of key business insights

## 🔄 Data Preparation
The dataset was prepared using Power Query. The data preparation process includes:
- Loading the dataset into Power BI
- Checking data types
- Removing unnecessary data
- Handling missing or inconsistent values
- Formatting columns
- Creating relationships between tables where required

## 🧮 Data Analysis
DAX measures and calculated fields are used to perform calculations and generate meaningful metrics. These measures support KPI cards, trend analysis, comparisons, and interactive dashboard visuals.

## 🎛️ Interactive Filters
The dashboard provides slicers and filters that allow users to:
- Select specific dates or periods
- Filter categories
- Compare different groups
- Analyze selected portions of the dataset
- Interact dynamically with dashboard visuals

## 📊 Dashboard Visualizations
The dashboard contains multiple visualizations designed for different types of analysis:
- KPI Cards – Overall summary and key metrics
- Bar/Column Charts – Category and group comparisons
- Line Charts – Trend and time-based analysis
- Tables/Matrix – Detailed data analysis
- Slicers – Interactive filtering

## 💡 Key Insights
The dashboard helps users identify:
- Overall performance
- Important trends over time
- Differences between categories
- Highest and lowest values
- Patterns and variations in the dataset
- Key metrics for decision-making

## 🚀 How to Use
1. Open `PowerBITask4.pbix` using Microsoft Power BI Desktop.
2. Navigate to the dashboard page.
3. Use the available slicers and filters.
4. Select different categories or time periods.
5. Interact with the charts and KPI cards.
6. Analyze the displayed trends and insights.
